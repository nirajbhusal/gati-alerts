# Gati design language

How Gati looks and why. The brand rules for outsiders (logo, colours, what not
to do) are in the [brand guidelines PDF](../assets/brand/print/gati-brand-guidelines.pdf)
and on the [About page](../about/index.html#brand). This file is for people
changing the site.

## Principles

1. **Quiet until it matters.** Pages are neutral, so a severity colour is always noticed.
2. **Source and time on everything.** No alert, number or map layer appears without them.
3. **Never by colour alone.** Severity is a word, an icon and a colour together.
4. **Nepali first.** Nepali text comes first; English follows. Numerals follow the language.
5. **Works on a weak phone and a weak signal.** Plain pages, small files, usable offline.
6. **Not a government body.** Nothing in the design may make Gati look official.

## Colour tokens

Defined as CSS variables at the top of `assets/css/gati.css`. Use the variable, never the hex.

| Token | Light | Use |
|---|---|---|
| Gati Red | `#E2362B` | Logo and app icon only |
| Navy | `#0B1424` | Wordmark, theme colour, dark surfaces |
| Crimson | `#DC143C` | Interface accent |
| River Teal | `#0F7C86` | Links, secondary accent |
| Glacier | `#7FD1D8` | Links on dark |
| Snow `--snow` | `#F7F9FB` | Page background |
| Mist `--mist` | `#D5DEE7` | Borders |
| Slate `--slate` | `#4A5A6A` | Secondary text |
| Ink `--ink` | `#14202B` | Body text |

Severity (CAP), reserved for alerts: Extreme `#8E1B14`, Severe `#D93025`,
Moderate `#F28C1E`, Minor `#F2C94C`, Info `#8F9BB3`.

Three themes, set by `data-theme` on `<html>`: `paper` (default, very light warm:
`--snow:#FCF6F4`, `--surface:#FFFCFB`, `--line:#EFE4E0`, `--ink:#2A2321`), `light` and `dark`.
Every new rule must read correctly in all three; body text needs 4.5:1 contrast.

## Type

- **Mukta** for Devanagari, **Inter** for Latin and numerals. Both served from `assets/fonts/`.
- Body 16 to 17 px, line height 1.6. Page title 28 to 32 px / 700. Labels 13 to 14 px in Slate.
- No letter-spacing and no italics on Devanagari.

## Shape and space

- Cards: 1 px border in `--line`, radius 10 to 14 px, no heavy shadows.
- Labels and chips: full pills.
- Touch targets at least 44 px high.
- Spacing steps: 4, 8, 12, 16, 24, 32 px.
- The three signal arcs from the logo may be used large and faint as a background motif. Nothing else from the logo is decoration.

## Components

- **Alert card:** severity stripe and word, headline in the agency's wording, source, source time, trust label (Official, Verified, Reported).
- **Buttons:** `.btn` for the main action; one main action per view.
- **Long lists:** fold after a sensible number with a "show more" button (see the pager in `assets/js/common.js`).
- **Bilingual text:** `<span class="ne-only">…</span><span class="en-only">…</span>` in HTML, `T(ne, en)` in scripts.

## Motion

Short and functional (150 to 250 ms). Respect `prefers-reduced-motion`. No decorative animation on alert content.

## Brand files

Everything in `assets/brand/` is generated by `python3 scripts/make_brand_kit.py`
from the vector logo drawn in `scripts/brand/make_svg.py`. Do not edit the
outputs by hand; change the script and run it again.
