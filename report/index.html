यो कसरी काम गर्छHow it works

  1. तलको फारम भर्नुहोस्।Fill in the form below.
  2. "GitHub मा पठाउनुहोस्" थिच्नुभयो भने हजुरको विवरण भरिएको GitHub Issue खुल्छ। पठाउन GitHub खाता चाहिन्छ (निःशुल्क)। त्यहाँ "Create/Submit" थिच्नुहोस्। "Send via GitHub" opens a GitHub Issue already filled with your details. Submitting needs a free GitHub account. Press "Create/Submit" there.
  3. रिपोर्ट GitHub मा सार्वजनिक हुन्छ। गतिको नागरिक रिपोर्ट पेजमा भने मोडेरेटरले जाँचेर पुष्टि गरेपछि मात्र देखिन्छ। The report is public on GitHub. Gati's citizen reports page shows it only after a moderator has checked and verified it.

गोपनीयताPrivacy

  • GPS हजुरको फोनमै पढिन्छ; हामी कुनै सर्भरमा पठाउँदैनौँ। रिपोर्टमा ठाउँ करिब ११ मिटरसम्म (४ दशमलव) मात्र राखिन्छ।
  • रिपोर्ट GitHub Issue बनेर सबैले देख्ने गरी राखिन्छ, र हजुरको GitHub नाम पनि देखिन्छ।
  • हजुरको सम्पर्क कहिल्यै सार्वजनिक गरिँदैन; यो पेजले त्यो कतै पठाउँदैन।
  • यो साइटमा कुकी, विज्ञापन वा हजुरलाई पछ्याउने कुनै कुरा छैन। फन्ट र नक्साको कोड यही साइटबाट आउँछ। नक्साको पृष्ठभूमि (टाइल) भने OpenStreetMap बाट आउँछ, त्यसैले नक्सा खोल्दा हजुरको ब्राउजर OSM सर्भरसँग जोडिन्छ।
  • GPS is read on your phone only; we do not send it to any server. Reports keep 4 decimals (about 11 m).
  • The report becomes a public GitHub Issue and shows your GitHub username.
  • Contact details are never published; this page does not send them anywhere.
  • No cookies, ads or tracking on this site. Fonts and map code are served from this site. Map background tiles come from OpenStreetMap, so opening a map makes your browser contact OSM's servers.
